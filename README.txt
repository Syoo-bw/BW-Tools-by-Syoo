Publikacja na GitHub Pages:
1. W repozytorium usuń/podmień obecny index.html.
2. Wgraj CAŁĄ zawartość tego folderu, zachowując foldery hp oraz przeciwnicy.
3. GitHub Pages: Settings -> Pages -> Deploy from a branch -> main -> /(root).
4. Po commicie odczekaj chwilę i odśwież stronę Ctrl+F5.

Dane wpisane w Kalkulatorze HP i wybór przeciwnika są zapisywane lokalnie w przeglądarce użytkownika (localStorage).
